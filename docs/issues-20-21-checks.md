# v1.6.72：启动窗口与托盘重载验证

日期：2026-10-15。范围：#20、#21；不改 DSH 内核或 npm 插件。

## 实现

- 新建窗口保持隐藏，取得主屏物理分辨率和工作区后设置物理尺寸、最小尺寸及位置，再沿用原有显示流程。宽 78%、高 88%，以工作区封顶；720×520 DIP 最小尺寸先乘 DPI，小工作区再封顶。无显示器信息时保留原有回退尺寸。恢复窗口不调用此逻辑。
- 托盘 `reload-frontend` 直接调用原生 `show_main_window`、`WebviewWindow::reload`。不经过页面事件监听，不调用后端停止、升级或重启。失败写入日志。六语言入口随既有菜单重建逻辑切换。
- 页面加载后沿用状态推送/拉取对账和 `dsh_webchat_url` 登录地址解析。未持久化的页面状态可能丢失。
