# v1.6.72 预发布版 / Prerelease

本次处理 #20 启动窗口尺寸与 #21 托盘界面重载。稳定版保持 v1.6.69。

- **启动尺寸与居中**：首次打开按主屏宽度 78%、高度 88% 计算，在扣除任务栏的工作区内居中；适配系统缩放，小屏限制在可用区域内。从托盘恢复不会重新调整窗口位置和大小。无法取得显示器信息时保留 1280×800 回退尺寸。
- **重新加载界面**：托盘 Open DSH 下新增入口，由原生窗口重载页面并唤回隐藏窗口，不执行后端重启。已保存的设置保留；未发送的输入、滚动位置等临时页面状态可能丢失。此功能提供恢复手段，不代表已解决所有卡死原因。
- 新入口支持六种语言；简体与繁体菜单的“检查前端更新”改为“检查应用更新”。

验证范围和限制见仓库 `docs/issues-20-21-checks.md`。不同屏幕缩放及原始卡死环境仍欢迎复测。安装方式：下载 exe，退出旧桌面后替换并重开；本次不需要升级 DSH 内核。npm 插件未发布。

## English

Prerelease addressing initial window geometry (#20) and a native tray reload action (#21). Stable Latest remains v1.6.69.

- Size the initial window to 78% of primary screen width and 88% of height, bounded and centered within its work area. Scale minimum dimensions correctly for DPI and cap them on small displays. Tray restoration preserves the adjusted geometry. Missing monitor information keeps the 1280×800 fallback.
- Add **Reload interface** after Open DSH in the tray menu, with six locales. Reveal the window and reload its webview without restarting the backend. Persisted settings remain; unsent drafts and other transient UI state may be lost. This is a recovery action, not a fix for every cause of freezing.
- Clarify the application-update label in Simplified and Traditional Chinese.

See `docs/issues-20-21-checks.md` for validation and limitations. Reporter-machine verification is still needed. Replace the executable after exiting the previous desktop and reopen. No DSH backend upgrade or npm plugin release is required.
