# v1.6.70 预发布版 / Prerelease

恢复会话完成通知（#18），并合并社区修复（#16）。

## 通知（#18）

- 会话完成通知自 dsh 0.1.2 起完全失效：事件源 `/api/events.host` 已删除，monitor 仍在连旧端点；握手不带凭证；帧格式（`server-request`/`host/session-status`）与新 mux 协议完全对不上；且 401-only 的分类器对"连接被掐断"这类失效连一条日志都不写。三项独立失效，任意一项都足以让通知永不触发。
- 适配方式（协议已对运行中的 dsh web 实测验证）：握手携带 webchat 登录换取的 `dsh-auth-…` 会话 cookie，连接 `ws://127.0.0.1:3080/api/remote.mux`，发送 `{type:"open", endpoint:"$events"}` 打开事件逻辑流，解析 `api-session/status(sessionId, running)`、`api-session/added(summary)`、`api-session/removed(sessionId)`；保留原有 true→false 边沿判定（配单元测试），稳态空闲不重弹。
- cookie 来源：dsh.rs 在 token 兑换后除种入 WebView2 外，同步保留给 Rust 侧消费（内存 + `%LOCALAPPDATA%\dsh-desktop\webauth-session.cookie`，过期时间随行）；壳重启后 monitor 仍可复用（附着模式没有新的 token 也能用）。
- 通知标题查询从已删除的点号端点改到 `session/list`，payload 使用新网关要求的 `args._request` 形状并携带凭证——否则每条通知都会退化成"任务已完成:一个会话"。
- 失效可见性：无 cookie / 401/403 → 静默 15 秒轮询、只记一条 Info；其他协议/IO 故障每段故障只记一条 Warn。

- 附带修复：壳此前会无视页面的"在侧栏打开"偏好强制唤起系统浏览器。

## English

Prerelease restoring session-finish notifications (#18) and merging community fixes (#16).

- The monitor now speaks dsh 0.1.2+ BrowserAuth: the launch-token-exchanged `dsh-auth-…` cookie rides the WS handshake to `/api/remote.mux`, the shell opens the gateway's `$events` logical stream and consumes `api-session/status|added|removed` emit frames, keeping the true→false edge semantics. Title lookup moved to `session/list` with the `args._request` payload. The cookie is retained for Rust-side consumers (memory + `webauth-session.cookie`) so a shell restart still authenticates. Auth gaps settle into a quiet 15 s poll logged once; any other breakage gets exactly one Warn line per failure streak.
- Merged PR #16: a reloaded page now pulls `dsh_current_status` to reconcile (fixes the stuck 「正在启动 DSH…」 boot spinner), and the shell's link backstop moved to the bubble phase so one click opens exactly one browser tab (five-path regression test included).
- README architecture bullets (zh+en) now describe the mux protocol.

## 升级 / Upgrade

下载 exe 替换旧版，从托盘退出后重新打开；DSH 后端无需重启。通知功能需要桌面端重新完成一次 webchat 登录换取（应用启动自动进行）。Replace the exe (quit from tray first); the DSH backend needs no restart. The notification feature authenticates automatically on the next app start.
