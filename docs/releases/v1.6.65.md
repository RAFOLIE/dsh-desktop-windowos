# v1.6.65 预发布版 / Prerelease

本版包含自 v1.6.63 以来的 npm 更新可靠性与双版本连接兼容性改进。稳定通道 Latest 保持 v1.6.63。

## 更新可靠性

- 更新前的 npm 版本查询等待上限调整为 90 秒；单次请求 20 秒，最多重试两次。查询失败发生在停止后端之前。
- 更新页显示当前阶段、等待时间和时间上限；失败时区分是否已经尝试安装，提供重试与查看日志入口。
- 超时日志保留可识别的 npm 错误代码、耗时与退出状态，避免记录任意错误输出中的私人路径或凭据。
- 安装上限仍为 10 分钟，不自动重复安装；重试会重新核验运行来源及目标版本。

## DSH 兼容性

- 已使用真实、隔离的 DSH **0.1.6-alpha.2** 与 **0.1.7-alpha.2** 验证启动探测、登录认证、网页聊天界面、跨站 iframe、草稿输入和刷新。
- 桌面升级不要求同时升级 DSH。保留其他旧协议适配，不以这两个版本作为启动白名单。
- 跨入 0.1.7 设置接口时，更新页和安装确认框提醒检查第三方插件的 settingsScope 兼容性。
- 本版不会自动升级或修改第三方插件；连接验证不代表所有插件或历史数据迁移均已验证。

## 使用与验证

下载下方 Windows exe 替换桌面程序，从托盘退出旧版后重新打开。npm 插件版本仍为 **1.5.12**。

验证：Rust 27 项通过；两个真实内核版本的独立连接测试通过；更新模型、更新界面、启动界面及 npm 查询重试测试通过；生产构建与内嵌资源已检查。浏览器嵌入验证使用 Edge，未以完整 Tauri 原生窗口自动化覆盖所有交互，也未执行真实模型请求。详见仓库 docs/backend-compatibility.md 和 docs/npm-update-timeout-checks.md。

## English

This prerelease includes all changes since v1.6.63. **Stable Latest remains v1.6.63.**

- Pre-install npm version queries now have a 90-second budget, a 20-second request timeout and up to two retries. Query failures occur before backend shutdown.
- The update UI reports phase, elapsed time, budget and whether installation was attempted, with retry and log actions. Diagnostics retain recognized error codes instead of arbitrary potentially sensitive output.
- Installation keeps its 10-minute limit and is never automatically repeated. Manual retries revalidate the running source and target version.
- Real isolated DSH **0.1.6-alpha.2** and **0.1.7-alpha.2** passed readiness, authentication, browser chat, cross-site iframe, draft-input and reload checks. Desktop updates do not require a backend upgrade; legacy adapters remain available.
- Updates crossing into the 0.1.7 settings API display a third-party settingsScope plugin compatibility reminder. This desktop release does not upgrade plugins, and connection checks do not certify every plugin or historical-data migration.

Download the Windows executable below and restart the desktop app after replacement. The npm plugin stays at **1.5.12**. Validation includes 27 Rust tests, both real-backend contracts, update/UI/startup tests, npm retry scenarios and a production build with embedded assets. Embedded-browser checks used Edge rather than full native Tauri window automation; no live model requests were made.
