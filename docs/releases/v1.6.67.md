# v1.6.67 预览版 / Prerelease

本版用于复测 Issues #15、#14、#13。稳定通道 Latest 保持 v1.6.66。

## 文件资源管理器（#15）

在隔离的 DSH 0.1.7-rc.2 中复现了“打开接口成功，但 Explorer 窗口隐藏”的情况。本版对桌面启动的 DSH 加入范围限定的兼容处理，仅将系统 Explorer 的隐藏启动选项改为显示；保留命令参数、回调、取消信号和 Promise 接口，不修改上游包、认证规则或全局环境。

请保存任务，安装本版并退出旧桌面后重开。若桌面连接的是已运行的外部 DSH，请从新版桌面使用“重启后端”，让修复随后端启动生效。随后分别测试右上角文件夹、交付物打开/定位入口。仅替换 exe 不会改变已经运行的外部后端。

## 快捷方式配置（#14）

中英 README 已明确说明没有 GUI 开关，并补充 profile cordis.patch.yml 的完整配置示例、生效方式以及关闭配置不会删除已有快捷方式的说明。

插件源码已保留迁移后的默认 Web 登录入口，并继续尊重显式自定义地址。**该插件修复尚未发布 npm，当前 npm 1.5.12 仍保留旧行为；本桌面 exe 不包含新版 npm 插件。** 现阶段可按更新后的 README 设置 createShortcut/createWebShortcut 并重启验证。

## 冷启动（#13）

保留 v1.6.63 已发布的修复：已安装候选等待 120 秒、npx 300 秒、只读能力探测及锁错误诊断。请复测 PATH/customDshPath 冷启动；无需为了验证本项升级 DSH。

## 验证与范围

Rust 28 项、插件 29 项、Explorer 兼容测试 4 项通过。Windows 实机对照覆盖打开目录、定位文件以及中文/逗号/等号路径，修复前窗口不可见、修复后可见。启用兼容处理后，DSH 0.1.6-alpha.2 与 0.1.7-alpha.2 的真实启动、认证、网页、iframe、草稿与刷新回归通过。生产构建和内嵌资源已核验。

这是隔离环境的复现和验证，仍需报告者在原机器复测；三个 Issue 保持打开。

## English

This prerelease invites retesting of #15, #14 and #13. Stable Latest remains v1.6.66.

**Explorer (#15):** isolated DSH 0.1.7-rc.2 reproduced successful HTTP responses with hidden Explorer windows. A narrowly scoped preload for desktop-started backends makes only hidden system-Explorer launches visible, preserving arguments, callbacks, cancellation and Promise behavior. It does not edit upstream packages, authentication or global environment. Save work, restart the updated desktop and restart any already-running external backend from the desktop to apply. Retest the top-right folder and deliverable open/reveal actions.

**Shortcuts (#14):** both READMEs now explain that no GUI switches exist and provide profile YAML configuration, restart instructions and non-deletion behavior. Source code preserves migrated default login shortcuts while honoring explicit custom URLs. **The plugin fix is not published to npm; npm 1.5.12 retains the old behavior, and this desktop executable does not ship an updated npm plugin.** Test the documented configuration separately.

**Startup (#13):** retains the fix released in v1.6.63: 120-second installed-candidate budget, 300 seconds for npx, file-based capability detection and writer-lock diagnostics. Retest PATH/customDshPath cold starts without needing a backend upgrade.

Validation: 28 Rust tests, 29 plugin tests, 4 Explorer compatibility tests; actual Windows open/reveal visibility checks with Unicode and separator characters; real 0.1.6-alpha.2 and 0.1.7-alpha.2 connection regressions with the preload enabled; production embedded assets verified. Reporter-machine confirmation remains outstanding, so the issues stay open.
