# v1.6.68 预览版 / Prerelease

新增托盘操作设置，修复最小化后无法恢复主窗口的问题（Issue #15）。稳定 Latest 保持 v1.6.66。

- 在“常规 → 窗口 → 托盘图标操作”中选择单击打开或双击打开，默认双击。保存后立即生效，重启后保留；托盘提示随设置与语言更新。
- 修复最小化后右键 Open DSH 无法恢复，以及托盘、通知和二次启动等入口的窗口恢复。恢复时显示窗口、解除最小化并聚焦；原本最大化的窗口恢复后仍保持最大化。
- 右键继续打开菜单。保存失败时保留原选择并显示提示，不把失败显示成已保存。

下载 exe 替换旧版，从托盘退出旧桌面后重新打开。测试托盘设置和窗口恢复不需要升级或重启 DSH 后端。本版保留 v1.6.67 的 Explorer 显示兼容修复；该修复仍需由新版桌面启动后端才能生效。本次未进一步优化文件资源管理器的打开速度，也未发布 npm 插件。

验证：30 项 Rust 测试通过；独立 Tauri 原生窗口验证通过（最小化恢复、隐藏恢复、最大化状态保留）；设置页验证覆盖默认值、保存、重新挂载、保存失败及中英明暗主题。生产构建和内嵌资源已核验。未自动操作用户正在使用的托盘或窗口，实际托盘手势由事件策略测试覆盖，仍邀请报告者在原机器复测。

## English

This prerelease adds configurable tray activation and fixes restoring minimized windows (#15). Stable Latest remains v1.6.66.

- General → Window → Tray icon action supports single or double click, defaulting to double click. Changes apply immediately, persist across restarts, and update the localized tray tooltip.
- Open DSH, tray activation, notifications and second-instance activation now show, unminimize and focus the main window. Previously maximized windows retain maximization after restoration.
- Right-click keeps the menu. Failed settings saves retain the previous selection and display an error.

Replace the executable and exit/reopen the desktop app. Testing these tray changes does not require a backend upgrade or restart. The v1.6.67 Explorer visibility fix remains included and still requires a desktop-started backend. This release does not further optimize Explorer launch speed or publish an npm plugin.

Validation: 30 Rust tests; isolated native Tauri minimized/hidden/maximized restoration; settings UI defaults, persistence across remounts, save failure and Chinese-dark/English-light rendering; production embedded assets. No interaction with the user's live tray/window was automated. Event-policy tests cover tray gestures; reporter-machine retesting remains requested.
