## English

**Startup:** installed DSH candidates now wait up to 120 seconds (npx: 300). Read-only package inspection replaces the profile-starting help probe. Equivalent candidates are deduplicated; writer-lock failures stop fallback without deleting locks. Browser handoff follows startup progress. Saved appearance is applied before window reveal, and chat no longer waits for the desktop updater.

**Appearance:** the current settings design replaces legacy styles. Six presets remain: DSH, Ocean, Forest, Violet, Amber and Rose; existing Codex colors remain as custom themes. Each light/dark theme supports accent, background, text, surface and frame colors. User colors are preserved without contrast restrictions or automatic recoloring. Copy/Paste works across theme cards using DSH theme JSON; Import and Reset remain available.

**Upgrade:** restart the desktop app after manual replacement. Existing settings and sessions are preserved; npm remains 1.5.12. Validation includes Rust regressions, theme models, browser UI/persistence/paste checks and embedded production assets. No destructive live-backend or lock-cleanup experiments were performed.
