# v1.6.71 预发布版 / Prerelease

针对 #18 会话通知失效与 #19 添加工作区后界面不刷新的候选修复。稳定 Latest 保持 v1.6.69，等待原机器复测后再决定是否转正。

- #18：重复会话信息不再清掉已知运行状态；最小化、隐藏或后台窗口允许完成通知，前台正在查看时仍抑制通知。逻辑事件流报错后重新连接，补充连接就绪、完成判定和 Windows 通知失败日志；被动监听正确跳过交互事件。
- #19：通过官方目录选择接口，由桌面创建归属于主窗口的文件夹选择框，替代外部无主对话框。保留页面和草稿，不刷新网页，不开放通用远程 Tauri 权限。旧版 DSH 没有该接口时保留原流程。

下载下方 exe，从托盘退出旧桌面后替换并重开。无需为本次桌面更新升级或重启 DSH 后端；若测试 #19，请保留报告中使用的 DSH 0.2.0-rc.2 环境作对照。

验证：40 项 Rust 测试通过，4 项可选测试忽略；目录选择桥接测试覆盖选择、取消、错误、草稿保留和来源校验；启动状态回归、生产构建与嵌入资源核验通过。目录桥接测试模拟了原生命令，未在报告者的 Windows 10 / WebView2 154 环境复现原故障；未发送真实模型任务。因此实际通知和目录选择后的显示仍需复测，两条 Issue 保持打开。npm 插件未发布。

## English

Candidate fixes for missing completion notifications (#18) and workspace updates not appearing after folder selection (#19). Stable Latest remains v1.6.69.

- Preserve running state across repeated session metadata events; allow notifications when hidden, minimized or unfocused, while suppressing them in the focused foreground window. Reconnect after logical-stream errors, improve diagnostics, and decline interactive events as a passive observer.
- Use the official desktop directory-picker hook with a native dialog owned by the main window. Preserve the page and drafts without reloads or general remote Tauri permissions. Older backends without the hook keep their existing flow.

Exit the previous desktop from the tray, replace the executable and reopen. No backend upgrade/restart is required for this desktop update. Keep the reported DSH 0.2.0-rc.2 environment for comparison when testing #19.

Validation: 40 Rust tests passed, 4 optional tests ignored; cross-origin picker bridge selection/cancellation/error/draft/source checks; boot regression; production build and embedded assets. Browser tests mock native commands. The reporter's Windows 10 / WebView2 154 rendering problem was not reproduced locally, and no live model task was submitted. Actual notifications and native picker behavior still require reporter confirmation; both issues remain open. No npm release.
