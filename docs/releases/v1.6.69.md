# v1.6.69 稳定版 / Stable

汇总 v1.6.67–v1.6.69 的 Explorer 打开兼容、托盘设置与窗口恢复修复。

## 文件与窗口

- 修复桌面启动的 DSH 0.1.7-rc.2 打开文件资源管理器时窗口被隐藏的问题（#15）。仅调整系统 Explorer 的隐藏启动选项，不修改官方包文件。
- 常规 → 窗口 → 托盘图标操作可选择单击或双击打开，默认双击；立即生效、重启保留，托盘提示随设置和语言更新。
- 修复最小化后右键 Open DSH 及其他窗口打开入口无法恢复；保留原最大化状态。
- 修复恢复窗口后最小化按钮残留灰色高亮的问题；窗口操作前清除高亮，鼠标再次移入或移动时恢复正常反馈，关闭按钮同类状态一并处理。

## 文档与升级

- 修正快捷方式设置说明，补充 profile YAML 示例（#14）。插件源码保留已迁移的网页入口；npm 已发布版本仍为 1.5.12，本次没有发布 npm 插件。
- 保留既有启动等待、只读能力探测与锁错误诊断改进（#13）。
- 下载 exe 替换旧版，从托盘退出后重新打开。托盘及高亮修复无需升级或重启 DSH 后端；Explorer 兼容修复需要由新版桌面启动后端，连接外部旧进程时应先保存任务，再按需重启后端。
- 本轮没有进一步优化 Explorer 打开速度。

## 验证

v1.6.68 的 30 项 Rust 测试、独立原生窗口恢复、托盘设置界面测试通过；#15 报告者确认文件夹打开、单/双击恢复、设置保存与最大化恢复正常。v1.6.69 浅色/深色界面回归覆盖残留 CSS 悬停、命令调用、鼠标重新高亮和失焦清除；本地用户确认灰色残留已修复。生产构建、内嵌资源与安装包校验通过。高亮自动测试使用模拟原生命令，真实恢复由本地用户复测确认。

## English

This stable release includes the changes from v1.6.67 through v1.6.69.

- Fix hidden Explorer windows in desktop-started DSH 0.1.7-rc.2 (#15), without modifying upstream package files.
- Add persistent single/double-click tray activation under General → Window, defaulting to double click, with localized tooltips.
- Restore minimized windows through Open DSH and other activation routes, preserving maximization.
- Clear stale title-bar button highlights before window operations; fresh pointer input restores normal hover feedback. This fixes the gray minimize-button highlight after restoration.
- Correct shortcut configuration documentation (#14), retaining existing startup diagnostics (#13). Published npm plugin remains 1.5.12; no npm package is released.

Exit the old desktop app from the tray and reopen the replacement executable. Tray fixes do not require a backend upgrade/restart. Explorer compatibility requires a backend started by the new desktop; save work before restarting an externally started backend. Explorer launch speed was not further optimized.

Validation: prior 30 Rust tests, isolated native window restoration and tray-settings UI checks; reporter confirmation of Explorer and tray restoration/persistence; light/dark hover regression tests and local user confirmation of the remaining highlight fix; production build, embedded assets and checksums. Hover UI automation mocks native commands; actual restoration was retested by the local user.
