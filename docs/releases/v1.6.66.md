# v1.6.66 稳定版 / Stable

本版汇总自 v1.6.63 以来的更新可靠性和 DSH 连接兼容性改进。

## npm 更新

- 支持经核验的外部 npm 全局 DSH 实例在桌面内更新，包括 alpha 通道。修复由终端或其他程序启动后，更新按钮不可用的问题。
- 确认框说明将停止当前 DSH 及其子进程、更新原安装位置，并由桌面重新启动。请先保存任务，暂停会自动重启 DSH 的外部启动器。
- 确认绑定当前进程；安装前复核来源、路径和版本。只停止已核验的进程树，端口被其他实例接替时中止安装。
- 更新前 npm 版本查询上限为 90 秒，单次请求 20 秒，最多重试两次。查询失败不停止当前后端；安装上限仍为 10 分钟，不自动重复安装。
- 显示更新阶段、等待时间和时间上限；失败时说明是否已尝试安装，提供重试与查看日志入口。诊断保留错误代码，避免记录任意输出中的私人路径或凭据。

## 连接兼容与插件提醒

- 已使用隔离的真实 DSH 0.1.6-alpha.2 与 0.1.7-alpha.2 验证启动探测、登录、网页聊天、跨站 iframe、草稿输入和刷新。
- 桌面更新无需同步升级 DSH；保留其他旧协议适配。
- 升级跨入 0.1.7 设置接口时，更新页和确认框提醒检查依赖 settingsScope 的第三方插件。不会自动更改插件，连接验证也不代表全部插件或历史数据迁移均已验证。

## 升级与验证

本版现为稳定通道 Latest，可通过桌面稳定通道更新，或下载下方 Windows exe 替换旧版并从托盘退出重开。仅升级桌面不会自动升级 DSH 内核。npm 已发布插件版本仍为 1.5.12，本轮不发布 npm。

验证包括 Rust 28 项、更新模型 6 项、更新与启动界面回归、npm 查询重试、双版本真实连接检查、生产构建及资源嵌入。外部实例界面测试覆盖确认、取消、PID 传递和非支持来源禁用；未在用户真实全局 DSH 上执行安装或停止测试。嵌入测试使用 Edge，并非完整 Tauri 原生窗口自动化；未执行真实模型请求。

## English

This stable release includes all update reliability and connection compatibility improvements since v1.6.63.

**npm updates:** verified global npm DSH instances started outside the desktop app can now update in place, including alpha-channel updates. Confirmation explains process-tree shutdown, installation at the same location and desktop restart. Consent is tied to the current PID; source, path and version are rechecked. Replacement listeners abort installation rather than being killed. Save work and pause external auto-restart supervisors first.

Pre-install version queries have a 90-second budget, a 20-second request timeout and up to two retries; failed queries leave the backend running. Installation retains its 10-minute limit and is never automatically repeated. The UI shows phase, elapsed time, budget, whether installation was attempted, retry and log actions. Diagnostics retain recognized error codes instead of arbitrary potentially sensitive output.

**Compatibility:** isolated real DSH 0.1.6-alpha.2 and 0.1.7-alpha.2 passed readiness, authentication, browser chat, cross-site iframe, draft-input and reload checks. Desktop updates do not require backend upgrades; legacy adapters remain. Updates crossing into the 0.1.7 settings API show a settingsScope plugin compatibility reminder. Plugins are not automatically modified; connection checks do not certify every plugin or data migration.

**Upgrade:** v1.6.66 is now stable Latest. Use the desktop stable channel or download the executable and restart the app after replacement. Updating the desktop alone does not upgrade DSH. The published npm plugin remains 1.5.12; no npm release is included.

Validation includes 28 Rust tests, 6 update-model tests, update/startup UI regressions, npm retry scenarios, both real-backend connection checks and production embedded assets. External-instance UI tests cover consent, cancellation, PID forwarding and unsupported sources. No live global DSH installation or user-backend termination was performed during tests. Embedded-browser checks used Edge rather than full native Tauri window automation; no live model requests were made.
