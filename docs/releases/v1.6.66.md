# v1.6.66 预发布版 / Prerelease

修复已安装全局 npm DSH、但由终端或其他程序启动时，桌面更新按钮不可用的问题。

- 核验运行包路径、npm 全局目录与启动命令后，外部实例也可在桌面内更新，包括 alpha 通道。
- 确认框明确说明：停止当前 DSH 及其子进程，通过 npm 更新原安装位置，再由桌面启动。请先保存任务，暂停会自动拉起 DSH 的外部启动器。
- 确认绑定当前进程；查询目标版本后重新核验来源。只停止核验过的进程树，端口被其他实例接替时中止安装，不清理接替进程。
- 保留 npm 超时诊断、失败重试、运行版本核验及 0.1.7 插件接口迁移提醒。自定义、npx 和无法核验的安装仍需手动处理。

家里机器请先下载安装本桌面版本，退出旧桌面后重开，再进入更新页选择 alpha 并确认更新。稳定 Latest 保持 v1.6.63；npm 插件本轮不发布。

验证：Rust 28 项通过、更新模型 6 项通过、界面回归通过（外部来源启用、取消不安装、确认参数、非支持来源禁用），生产构建通过。测试未对用户的真实全局 DSH 执行安装或停止操作；家里机器的实际网络与安装权限仍由运行时核验。

## English

This prerelease enables desktop updates for verified global npm DSH instances started outside the desktop app, including alpha-channel updates.

The confirmation explains that the selected DSH process and its children will stop, the same npm installation will update, and the desktop will restart it. Save work and pause external auto-restart supervisors first. Consent is bound to the current PID; source and package path are rechecked before stopping that process tree. A replacement listener aborts installation rather than being killed.

Custom, npx and unverified sources remain manual. Existing timeout diagnostics, retries, running-version checks and the 0.1.7 plugin migration reminder remain available. Stable Latest remains v1.6.63; no npm plugin release is included.

Validation: 28 Rust tests, 6 update-model tests, browser UI regressions and production build passed. No live global DSH installation or user-backend termination was performed during testing.
